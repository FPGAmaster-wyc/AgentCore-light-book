AgentCore-Light macOS 客户使用手册

第一步 · 下载软件

下载 macOS 客户端

适用于所有 Mac（Intel 芯片和 Apple 芯片都可以）。下载后解压，把 AgentCore-Light.app 拖进「应用程序」文件夹。

下载 macOS 版 ↓

当前版本 v2.1.2

第一次运行被系统拦住了？

App 没有加入 Apple 开发者计划、也没有做公证，macOS 提示“无法验证开发者”属于正常现象，不是病毒。

  • “无法验证开发者”或“Apple 无法检查是否包含恶意软件” → 系统设置 → 隐私与安全性 → 点“仍要打开”
  • “已损坏，无法打开。你应该将它移到废纸篓。” → 打开“终端”执行：
    xattr -dr com.apple.quarantine /Applications/AgentCore-Light.app
  • 双击没有反应 → 确认已把 App 拖进“应用程序”文件夹，而不是在解压出来的文件夹里直接运行
看详细说明 → 2.2 系统提示“无法验证开发者”怎么办

适用产品：AgentCore-Light 桌面状态指示灯

适用软件：AgentCore-Light macOS 客户端

磁铁片粘贴与售后提醒

包装内附有磁铁片，方便将设备固定在合适的位置。请在收到商品后，先完成开机、连接、灯光、蜂鸣器等全部功能测试，再决定粘贴位置。磁铁片撕开背胶并粘贴后，不支持无理由退货。如发现商品异常，请勿粘贴，先联系售后处理。

包装内附有一片酒精棉片

设备在出厂组装和测试时会接触工作台，外壳上可能留下少量灰尘或指纹，属于正常现象——用包装内附带的酒精棉片擦拭一遍即可擦净。每台设备出厂前都做过完整功能测试，灯效、蜂鸣器、按键均确认正常，功能没有问题，请放心使用。

AgentCore-Light 通过三色灯和提示音展示电脑或 AI 工具的工作状态。Mac 用户可使用蓝牙无线连接，也可使用 USB 数据线有线连接。

#1. 状态速查

指示状态含义您需要做什么
三色灯短暂亮起设备正在开机等待进入连接状态
红灯闪烁蓝牙模式，等待 Mac 连接在 AgentCore-Light 中启动蓝牙模式
黄灯闪烁USB 串口模式，等待 Mac 软件连接插入 USB 数据线，并在软件中启动 USB 串口模式
绿灯呼吸当前连接方式已建立，设备处于空闲待命状态可以开始使用软件或 AI 工具
所有状态灯熄灭设备已关机长按按键 3 秒开机

「绿灯呼吸」指绿灯缓慢地一亮一暗，表示设备已连接、正在待命，不是闪烁也不是故障。

#2. 安装 macOS 软件

#2.1 安装步骤

安装包对 Intel 芯片和 Apple 芯片的 Mac 都适用，不用分辨芯片型号：

  1. 解压下载到的 AgentCore-Light-mac.zip。
  2. 将解压出来的 AgentCore-Light.app 拖入 Applications（应用程序） 文件夹。
  3. 第一次运行时，在“应用程序”中按住 Control 键点按 AgentCore-Light.app，选择“打开”。
  4. 软件启动后会自动打开浏览器控制台；若未自动打开，请在浏览器访问：http://127.0.0.1:18793/。

请将 App 保留在“应用程序”文件夹中。这样登录自启动、AI 工具连接和在线更新都可以正常使用。

第一次打开时，macOS 很可能不允许运行，提示“无法验证开发者”或“已损坏，无法打开”。这是未签名软件的正常现象，不是 App 有问题，处理方法见下一节 2.2。

Apple 芯片（M1 / M2 / M3 / M4）的 Mac 第一次打开时，系统可能提示安装 Rosetta，这是 macOS 的兼容运行机制：点“安装”，按提示完成即可，之后正常使用。

#2.2 系统提示“无法验证开发者”怎么办

AgentCore-Light 由一个独立开发者制作，没有加入 Apple 开发者计划，也没有做公证（Notarization）——这两项都需要每年付费。所以第一次打开时，macOS 通常会拦下来。这是缺少签名与公证导致的，不是 App 里有病毒。

这个 App 实际上做什么：

  • 只在本机运行。控制台网页只监听 127.0.0.1，也就是只有这台 Mac 打得开，同一个局域网里的其它设备也访问不到。
  • 除了检查软件更新，不向外部发送任何数据。
  • 开机自启动写在当前用户的登录项里，不需要管理员密码，也不会改动系统设置或其它软件。

按提示类型处理：

① “无法打开，因为 Apple 无法检查其是否包含恶意软件”

这是 macOS 自带的 Gatekeeper 拦截。打开 系统设置 → 隐私与安全性，向下滚动找到“安全性”一栏，这里会列出刚才被拦下的 AgentCore-Light，点 “仍要打开”，再输入开机密码确认。

② “无法打开，因为无法验证开发者”

处理方法与上面完全相同：系统设置 → 隐私与安全性 → 仍要打开。

从 macOS 15（Sequoia）开始，Apple 已经取消了“按住 Control 点按”跳过检查的做法，只能从“隐私与安全性”里放行。所以第 3 步没成功时，直接走这里。

③ “AgentCore-Light 已损坏，无法打开。你应该将它移到废纸篓。”

这句话最容易让人误会成文件坏了或者带毒。实际上它通常是 macOS 给“从网上下载来的 App”打的隔离标记造成的，App 本身没有问题。去掉这个标记即可：

  1. 打开 访达 → 应用程序 → 实用工具 → 终端。
  2. 粘贴下面这行命令，按回车，然后输入开机密码：
bash
xattr -dr com.apple.quarantine /Applications/AgentCore-Light.app
  1. 重新打开 AgentCore-Light.app，就可以正常启动了。

如果 App 不在“应用程序”文件夹里，请把上面命令最后的路径换成实际位置。

运行之后还是不放心？

这个 App 没有请求麦克风、摄像头、通讯录、定位、屏幕录制等任何敏感权限。可以在 系统设置 → 隐私与安全性 里逐项查看确认。

#3. 开机、关机和模式切换

#开机与关机

  • 开机：长按设备按键约 3 秒。达到时间后设备会立即显示开机灯效，并默认进入蓝牙模式。
  • 关机：长按设备按键约 3 秒。达到时间后所有状态灯关闭，设备进入低功耗状态。
  • 插入 USB 只用于充电或 USB 通信，不会自动开机。

#切换连接方式

设备开机后默认蓝牙模式。短按一次设备按键即可切换：

text
蓝牙模式（红灯闪烁）
        ⇅ 短按按键
USB 串口模式（黄灯闪烁）

设备一次只启用一种连接方式，以降低功耗并避免连接冲突。

#4. 使用蓝牙连接

  1. 开机后确认设备红灯正在闪烁。
  2. 在 Mac 的“系统设置”中确认蓝牙已打开。
  3. 打开 AgentCore-Light.app，进入浏览器控制台。
  4. 点击启动蓝牙模式。
  5. 等待软件搜索并连接设备；设备绿灯呼吸即表示连接成功。

macOS 蓝牙由 AgentCore-Light 自动搜索和连接。通常无需在 macOS 蓝牙设备列表中手动添加设备；如软件未找到设备，请先确认设备处于红灯闪烁状态，再重新启动蓝牙模式。

#5. 使用 USB 串口连接

  1. 确保设备已经开机。
  2. 短按一次按键，确认黄灯闪烁。
  3. 使用支持数据传输的 Type-C 数据线连接设备与 Mac。
  4. 打开 AgentCore-Light 控制台，点击启动 USB 串口模式。
  5. 等待软件连接成功；设备绿灯呼吸即表示可以使用。

Mac 会自动识别设备，无需手动输入端口名称。如果软件提示没有找到设备，请更换支持数据传输的 Type-C 数据线后重试。

#6. 控制台使用

设备绿灯呼吸后，可以在控制台中：

  • 测试红、黄、绿灯的点亮与闪烁；
  • 调整整体灯光亮度（默认 30%）；
  • 开启、关闭或调节蜂鸣器音量；
  • 查看电量百分比、电池电压、USB 接入状态和最近更新时间；
  • 在“连接 AI 工具”中安装所需 AI 工具连接。

亮度滑块松开后会立即生效，并保存在本机；下次启动软件或重新连接设备时会自动恢复。

#7. 连接 AI 工具

  1. 先完成蓝牙或 USB 连接，确认设备绿灯呼吸。
  2. 在控制台打开连接 AI 工具。
  3. 选择需要连接的 AI 工具，按页面提示完成安装。
  4. 按提示重启对应 AI 工具或新建会话。
  5. AI 工作时，设备会自动显示工作中、完成、报错或等待确认等状态。

#设备状态灯效对照

AI 工具工作时，设备会自动按下面的方式显示当前状态：

状态灯效说明
空闲 IDLE绿灯呼吸没有任务在跑；连续空闲会自动熄灯休眠
工作 BUSY黄灯慢闪正在调用工具或执行任务，约 1 秒闪一次
等待确认 WAIT_CONFIRM黄灯常亮需要你授权或确认
报错 ERROR红灯快闪任务失败或出错
任务完成 SUCCESS绿灯呼吸任务成功时绿灯呼吸并响「上行提示」音，5 秒后回到空闲

灯光亮度可在控制台调整（默认 30%）；蜂鸣器可以整体关闭，也可以单独调整音量。连续空闲 10 分钟会自动熄灯休眠，蓝牙断连 5 分钟自动关机，详见第 8 章。

#8. 待机、休眠与自动关机

#8.1 空闲时的呼吸灯

连接 AI 工具后，灯光会交给软件接管：没有任务在跑时，绿灯以低亮度呼吸显示，比正常工作亮度暗一些，也是省电设计。刚建立连接、软件还没接管灯光时，绿灯同样是呼吸显示——看到绿灯在缓慢地一亮一暗，就表示连接已经就绪。

#8.2 连续空闲自动熄灯（休眠）

连续空闲 10 分钟（默认）后，设备会熄灭全部状态灯、进入休眠，进一步省电。休眠期间连接保持不断；AI 工具有新任务时，灯会自动亮回来，不需要按任何按键。

#8.3 蓝牙断连自动关机

蓝牙模式下，如果连续 5 分钟没有连接（例如 Mac 关机、蓝牙关闭或软件退出），设备会自动关机；插着 USB 充电时同样会进入关机状态。需要使用时，长按按键约 3 秒重新开机。

上面两个时间都可以调整：空闲熄灯默认 10 分钟、断连关机默认 5 分钟，范围都是 0～3600 秒，设为 0 表示关闭对应的自动动作。开发者可通过 API 命令 IDLE_SLEEP_SEC:、BT_DISCONNECT_OFF_SEC: 修改（见 API 调用手册第 15 节）；普通用户如需修改，请联系售后。

#8.4 充电与续航

  • 使用常规 USB 电源为设备充电。
  • USB 接入且未充满时，充电指示灯亮；充满后完成指示灯亮。
  • 使用电池供电时，充电和完成指示灯均关闭，这是正常的节能设计。
  • 长时间不用时，请长按按键关机。

#9. 常见问题

#提示“需要安装 Rosetta”

安装包对两种芯片的 Mac 都适用。Apple 芯片（M1 / M2 / M3 / M4）的 Mac 第一次打开时，系统会提示安装 Rosetta（macOS 的兼容运行机制），点“安装”并按提示完成即可，之后正常使用。若误点了“否”，重新双击 AgentCore-Light.app 会再次提示。

#软件无法打开

绝大多数情况是 macOS 的安全拦截，不是 App 有问题，详细步骤见 2.2 系统提示“无法验证开发者”怎么办。对照下面三种情况处理：

  • “无法验证开发者”或“Apple 无法检查其是否包含恶意软件” → 打开“系统设置 → 隐私与安全性”，在“安全性”一栏点“仍要打开”。
  • “已损坏，无法打开。你应该将它移到废纸篓。” → 在终端执行 xattr -dr com.apple.quarantine /Applications/AgentCore-Light.app，然后重新打开。
  • 双击完全没有反应 → 确认 App 已经拖进“应用程序”文件夹，而不是在解压出来的文件夹里直接运行。

#蓝牙模式一直红灯闪烁

  • 确认 Mac 蓝牙已打开。
  • 确认控制台已点击“启动蓝牙模式”。
  • 关闭并重新打开蓝牙模式，或重启设备后重试。

#USB 模式一直黄灯闪烁

  • 确认已短按按键切换到 USB 串口模式。
  • 确认使用的是数据线，而非仅充电线。
  • 重新插拔数据线后，在控制台再次启动 USB 串口模式。

#灯光没有变化

  • 确认设备绿灯呼吸。
  • 在“灯光控制”中先测试任意颜色。
  • 确认亮度没有设为 0%。

#设备外壳上有灰尘或指纹，是别人用过的吗？

不是。每台设备出厂前都经过组装和完整功能测试（开机、灯效、蜂鸣器、按键），测试、装箱时会接触工作台，外壳上留下少量灰尘或指纹属于正常现象，不影响使用。用包装内附带的酒精棉片擦拭一遍即可擦净，功能没有问题。

#空闲一会儿，灯自己灭了

不是故障：连续空闲 10 分钟设备会自动熄灯休眠，连接并没有断开，AI 工具有新任务时会自动亮回来，不需要按任何按键。详见 8.2 连续空闲自动熄灯（休眠）。

#设备自己关机了

蓝牙模式下连续 5 分钟没有连接（电脑关机、蓝牙关闭或软件退出），设备会自动关机，插着 USB 充电时也一样。长按按键约 3 秒即可重新开机。详见 8.3 蓝牙断连自动关机。

#10. 使用注意事项

  • 请勿自行拆开设备、短接接口或使用不匹配的电源。
  • 请避免在潮湿、高温或易燃环境中使用和充电。
  • 固件升级、维修或异常排查请联系售后，不建议客户自行操作。
