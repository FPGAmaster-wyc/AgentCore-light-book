The magnetic plate, and returns

A magnetic plate is included so you can mount the device wherever it suits you. Please power it on and test everything first — power, connection, lights, buzzer — before you decide where to stick it. Once the backing is peeled off the magnetic plate and it is attached, the item can no longer be returned under our no-questions-asked policy. AgentCore-Light shows what your computer or your AI tools are doing through three coloured lights and a buzzer. On Linux you can connect wirelessly over Bluetooth, or wired over a USB cable.

#1. Status at a glance

LightMeaningWhat to do
All LEDs flashThe device is powering onWait for it to enter a connection mode
Red blinkingBluetooth mode, waiting for the computer to connectStart Bluetooth mode in AgentCore-Light
Yellow blinkingUSB serial mode, waiting for the app to connectPlug in the USB cable and select Start USB mode in the app
Green breathingThe current connection is up; the device is idle and standing byYou can start using the app or your AI tools

“Green breathing” means the green light fading slowly up and down. It means the device is connected and standing by — it is not blinking, and it is not a fault.

#2. Installing and starting the Linux app

Switch the app to English first. The app starts up in Chinese. Open Settings (top right) → Language → English. Every button name in this manual is the one you will see after that — for example Start Bluetooth mode and Start USB mode. Your choice is remembered on this computer.

#2.1 Installation steps

  1. Unzip the included AgentCore-Light-linux.tar.gz.
  2. Open a terminal and change into the folder you extracted.
  3. The first time only, run:
bash
chmod +x AgentCore-Light
  1. Start the app:
bash
./AgentCore-Light
  1. The app opens its local console; if it does not open by itself, visit http://127.0.0.1:18793/ in your browser.

The Linux app needs no Python installation and no compiler toolchain. Just run the included AgentCore-Light file directly.

#2.2 What to do when your browser or security software says “not safe”

AgentCore-Light is made by an independent developer. It is not in any distribution’s software repository and carries no repository signature, so you may see a warning when you download or extract it. That is normal for unsigned software — it is not a problem with the software.

What to do, by the kind of prompt you get:

① Your browser says “this file isn’t commonly downloaded and might not be safe”

In your browser’s download list, choose Keep (in Firefox: “Allow download”).

② The archive disappears after downloading, or is deleted automatically

Some systems’ security policies clean up uncommon archives on their own. Check your browser’s download history and your security software’s activity log, choose Restore or Keep, then extract the archive again.

③ Your antivirus or security software flags it

Linux desktop distributions rarely ship with antivirus software. If you installed security software separately, add AgentCore-Light to its trusted / allow list / exclusions.

What the software actually does:

  • It runs entirely on your own machine. The console page listens on 127.0.0.1 only, so only this computer can open it — other devices on the same local network cannot reach it.
  • It sends no data anywhere, apart from checking for software updates.
  • The permission step in chapter 3 only adds your user to the dialout group — the standard way to reach serial devices on Linux. It installs no background service.
  • Unless you switch on Start at sign-in yourself in chapter 8, the app leaves nothing resident on the system.

The app runs as an ordinary user throughout. It does not need sudo, and it should not be started with sudo. Any instruction telling you to run sudo ./AgentCore-Light is wrong.

#3. Setting permissions before your first USB connection

The first time you use USB serial, Linux may need to grant your account access to serial ports. In a terminal, run this once:

bash
sudo usermod -aG dialout $USER

After that, sign out and sign back in to Linux, or restart the computer. Then start AgentCore-Light.

This step is needed only once. Do not start the app with sudo ./AgentCore-Light.

#4. Powering on, powering off and switching modes

#Powering on and off

  • Powering on: press and hold the device button for about 3 seconds; the device enters Bluetooth mode by default, with red blinking.
  • Powering off: press and hold the device button for about 3 seconds; when the time is up the device switches its status lights off and powers down to a low-power state.
  • Plugging in USB does not power the device on. When you want to use it, you still need to press and hold the button.

#Switching connection modes

A single short press of the device button switches between the two modes:

text
Bluetooth mode (red blinking)
        ⇅ short press
USB serial mode (yellow blinking)

The device runs one transport at a time, to reduce power draw and keep the connection stable.

#5. Connecting over Bluetooth

  1. After powering on, check that the red light is blinking.
  2. Check in your Linux system settings that Bluetooth is switched on; if your computer has no Bluetooth, use the USB connection instead.
  3. Start AgentCore-Light and open the console.
  4. Click Start Bluetooth mode.
  5. Wait while the app searches for the device and connects; green breathing on the device means it worked.

On Linux, AgentCore-Light searches for the device and connects on its own. You normally do not need to pair it manually in the system Bluetooth settings first. If the device is not found, check that it is showing red blinking, and that the system Bluetooth service is switched on.

#6. Connecting over USB serial

  1. Make sure the device is powered on.
  2. Short-press the button once and check that the yellow light starts blinking.
  3. Connect the device to your Linux computer with a Type-C cable that supports data transfer.
  4. In the console, click Start USB mode.
  5. Wait for the app to connect; green breathing on the device means you are ready to go.

If you see “permission denied”, or the app cannot find the USB device, complete the permission step in chapter 3 first, then unplug and replug the cable and scan again.

#7. The console and your AI tools

Once the device shows green breathing, you can do the following in the console:

  • test the red, yellow and green lights, steady on or blinking;
  • adjust the overall light brightness (default 30%);
  • turn the buzzer on or off and set its volume;
  • check battery level, battery voltage and whether USB power is connected;
  • open Connect AI tools and follow the prompts to install the AI tool integrations you need.

Once an AI tool is connected, the device can show working, done, error and waiting-for-confirmation states on its own.

#Status light reference

While your AI tools work, the device shows the current state like this:

StateLightNotes
Idle IDLEGreen breathingNothing is running; after a while idle the light goes to sleep
Working BUSYYellow slow blinkA tool call or task is running, about once a second
Waiting WAIT_CONFIRMYellow steadyThe AI needs you to authorise or confirm something
Error ERRORRed fast blinkThe task failed or hit an error
Done SUCCESSGreen breathingOn success the green light breathes and the “rising” tone plays, then it returns to idle after 5 seconds

Brightness can be adjusted in the console (default 30%). The buzzer can be switched off entirely or have its volume set on its own. After 10 minutes continuously idle the light goes to sleep; after 5 minutes with Bluetooth disconnected the device powers off. See chapter 9.

#8. Setting up start at sign-in (optional)

If you want AgentCore-Light to start automatically every time you sign in to Linux, run this once in the folder where you extracted the app:

bash
./AgentCore-Light install

The app then runs as a background service under your own user. You normally do not need any other commands; to stop it starting automatically, switch Start at sign-in off in the console.

#9. Standby, sleep and auto power-off

#9.1 The idle breathing light

Once an AI tool is connected, the light is handed over to the app: with nothing running, the green light shows low-brightness breathing, a little dimmer than the normal working brightness, which is also a power-saving measure. Right after connecting, before the app has taken over the light, the green light breathes in the same way — seeing it fade slowly up and down means the connection is ready.

#9.2 Going to sleep after a while idle

After 10 minutes continuously idle (the default), the device turns all status lights off and goes to sleep, saving more power. The connection stays up while it sleeps; when your AI tool has new work the light comes back on by itself, with no button press needed.

#9.3 Auto power-off when Bluetooth drops

In Bluetooth mode, if there is no connection for 5 minutes continuously (the computer shut down, Bluetooth was switched off, or the app quit), the device powers itself off; this happens even while USB charging is plugged in. When you want to use it again, press and hold the button for about 3 seconds to power on.

Both of those times can be changed: idle sleep defaults to 10 minutes and disconnect power-off to 5 minutes, both in the range 0–3600 seconds, where 0 turns the automatic action off. Developers can change them with the API commands IDLE_SLEEP_SEC: and BT_DISCONNECT_OFF_SEC: (see section 15 of the API manual); everyone else can contact support.

#9.4 Charging and battery life

  • You can charge the device from any ordinary USB power source.
  • While USB is connected and the battery is not full, the charge indicator is on; once it is full, the full indicator is on.
  • On battery power both the charge and full indicators are off, which is normal power-saving design.
  • When you are not using it, press and hold the button to power it off.

#10. Troubleshooting

#The app will not start

  • Check that you have run chmod +x AgentCore-Light in the app’s folder.
  • Run ./AgentCore-Light from a terminal; do not double-click unknown files.

#USB connection fails, or says permission denied

  • Check that you have run the dialout permission command from chapter 3, and signed out and back in.
  • Swap in a Type-C cable that supports data transfer.
  • Check that the device is in USB serial mode, showing yellow blinking.

#Bluetooth mode keeps blinking red

  • Check that Bluetooth is switched on in Linux and that your computer has Bluetooth.
  • Click Start Bluetooth mode in the console.
  • Switch Bluetooth off and back on, then start Bluetooth mode again.

#The light does not change

  • Check that the device shows green breathing.
  • In Light control, test any colour first.
  • Check that the Brightness is not set to 0%.

#There is dust or a fingerprint on the shell — has it been used?

No. Every unit is assembled and fully function-tested before it leaves the factory (power, light effects, buzzer, button). It is handled on the workbench during testing and packing, so a little dust or a fingerprint on the shell is normal and does not affect anything. One wipe with the alcohol pad in the box clears it; the unit works fine.

#After a while idle the light goes out by itself

Not a fault: after 10 minutes continuously idle the device turns the lights off and sleeps. The connection is not dropped, and the light comes back by itself when your AI tool has new work — no button press needed. See 9.2 Going to sleep after a while idle.

#The device powered itself off

In Bluetooth mode, after 5 minutes with no connection (computer shut down, Bluetooth off, or app quit) the device powers itself off — plugging in USB does not prevent it. Press and hold the button for about 3 seconds to power on again. See 9.3 Auto power-off when Bluetooth drops.

#11. Precautions

  • Do not open the device, short its connectors, or use a power supply that does not match.
  • Avoid using or charging it in damp, hot or flammable surroundings.
  • For firmware updates, repairs or fault-finding, contact support — we do not recommend customers doing this themselves.
