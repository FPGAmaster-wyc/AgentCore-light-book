# AgentCore-Light — 使用手册 / User Manual

AgentCore-Light（桌面 AI 工作状态指示灯）的客户使用手册网页，中英双语。

This is the overseas mirror of the AgentCore-Light manual site. Chinese and English
versions are both here; the site picks the right one automatically and you can switch
with the **EN / 中文** button in the header.

## 下载 / Downloads

安装包不在这个仓库里，在 [Releases](../../releases/latest) 页面：

| 平台 / Platform | 文件 |
| --- | --- |
| Windows 10 / 11 | `AgentCore-Light.zip` |
| macOS（Intel 与 Apple 芯片通用） | `AgentCore-Light-mac.zip` |
| Linux x86_64 | `AgentCore-Light-linux.tar.gz` |
| Python 例程（开发者） | `AgentCore-API-Python.zip` |

链接用的是 `releases/latest/download/…`，永远指向最新版，不用记版本号。
