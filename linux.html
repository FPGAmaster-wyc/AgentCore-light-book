AgentCore-Light Linux 客户使用手册

第一步 · 下载软件

下载 Linux 客户端

适用于 x86_64 Linux。解压后执行 chmod +x AgentCore-Light。

下载 Linux 版 ↓

当前版本 v2.1.2

第一次运行被系统拦住了？

软件没有进入发行版软件仓库、也没有仓库签名，下载时提示“不安全”属于正常现象，不是病毒。

  • 浏览器提示“此文件不常下载，可能不安全” → 在下载列表里选“保留”
  • 压缩包被自动删除 → 在下载记录或安全软件里选“恢复”/“保留”，再重新解压
  • 安全软件报警 → 在它的信任区 / 白名单里添加 AgentCore-Light
看详细说明 → 2.2 浏览器或安全软件提示“不安全”怎么办

适用产品：AgentCore-Light 桌面状态指示灯

适用软件：AgentCore-Light Linux 客户端

磁铁片粘贴与售后提醒

包装内附有磁铁片，方便将设备固定在合适的位置。请在收到商品后，先完成开机、连接、灯光、蜂鸣器等全部功能测试，再决定粘贴位置。磁铁片撕开背胶并粘贴后，不支持无理由退货。如发现商品异常，请勿粘贴，先联系售后处理。

包装内附有一片酒精棉片

设备在出厂组装和测试时会接触工作台，外壳上可能留下少量灰尘或指纹，属于正常现象——用包装内附带的酒精棉片擦拭一遍即可擦净。每台设备出厂前都做过完整功能测试，灯效、蜂鸣器、按键均确认正常，功能没有问题，请放心使用。

AgentCore-Light 通过三色灯和提示音展示电脑或 AI 工具的工作状态。Linux 用户可使用蓝牙无线连接，也可通过 USB 数据线有线连接。

#1. 状态速查

指示状态含义您需要做什么
三色灯短暂亮起设备正在开机等待进入连接状态
红灯闪烁蓝牙模式，等待电脑连接在 AgentCore-Light 中启动蓝牙模式
黄灯闪烁USB 串口模式，等待电脑软件连接插入 USB 数据线，并在软件中启动 USB 串口模式
绿灯呼吸当前连接方式已建立，设备处于空闲待命状态可以开始使用软件或 AI 工具
所有状态灯熄灭设备已关机长按按键 3 秒开机

「绿灯呼吸」指绿灯缓慢地一亮一暗，表示设备已连接、正在待命，不是闪烁也不是故障。

#2. 安装与启动 Linux 软件

#2.1 安装步骤

  1. 解压随附的 AgentCore-Light-linux.tar.gz。
  2. 打开终端，进入解压后的目录。
  3. 仅首次使用时执行：
bash
chmod +x AgentCore-Light
  1. 启动软件：
bash
./AgentCore-Light
  1. 软件会打开本地控制台；若未自动打开，请在浏览器访问：http://127.0.0.1:18793/。

Linux 版不需要安装 Python 或编译环境。请直接运行随附的 AgentCore-Light 文件。

#2.2 浏览器或安全软件提示“不安全”怎么办

AgentCore-Light 由一个独立开发者制作，没有进入任何发行版的软件仓库，也没有仓库签名，所以下载和解压时可能遇到提示。这是未签名软件的正常现象，不是软件有问题。

可能遇到的提示：

① 浏览器提示“此文件不常下载，可能不安全”

在浏览器的下载列表里选择 “保留”（Firefox 里是“允许下载”）。

② 下载后压缩包不见了，或被自动删除

个别系统的安全策略会直接清理不常见的压缩包。请检查浏览器的下载记录和安全软件的处理记录，选择“恢复”或“保留”，再重新解压。

③ 杀毒软件或安全软件报警

Linux 桌面发行版自带杀毒软件的情况很少。如果你另外装了安全软件，在它的“信任区 / 白名单 / 排除项”里添加 AgentCore-Light 即可。

这个软件实际上做什么：

  • 只在本机运行。控制台网页只监听 127.0.0.1，也就是只有这台电脑打得开，同一个局域网里的其它设备也访问不到。
  • 除了检查软件更新，不向外部发送任何数据。
  • 第 3 章的权限设置，只是把当前用户加入 dialout 组——这是 Linux 上访问串口设备的标准做法，不会安装后台服务。
  • 除非你在第 8 章主动开启“登录后自动启动”，否则软件不会在系统里留下任何常驻项。

软件全程以普通用户身份运行，不需要、也不应该用 sudo 启动。凡是要求你 sudo ./AgentCore-Light 的说法都是不对的。

#3. 首次使用 USB 前的权限设置

首次使用 USB 串口时，Linux 可能需要授予当前账户访问串口的权限。在终端执行一次：

bash
sudo usermod -aG dialout $USER

执行后请注销并重新登录 Linux，或重启电脑。完成后再启动 AgentCore-Light。

此步骤只需执行一次。请勿使用 sudo ./AgentCore-Light 启动软件。

#4. 开机、关机和模式切换

#开机与关机

  • 开机：长按设备按键约 3 秒；设备默认进入蓝牙模式，红灯闪烁。
  • 关机：长按设备按键约 3 秒；达到时间后设备关闭状态灯并进入低功耗状态。
  • 插入 USB 不会自动开机，需要使用时仍需长按按键。

#切换连接方式

短按一次设备按键即可在两种模式之间切换：

text
蓝牙模式（红灯闪烁）
        ⇅ 短按按键
USB 串口模式（黄灯闪烁）

设备一次只启用一种通信模式，以降低功耗并保证连接稳定。

#5. 使用蓝牙连接

  1. 开机后确认设备红灯正在闪烁。
  2. 在 Linux 系统设置中确认蓝牙已开启；如电脑没有蓝牙，请使用 USB 连接方式。
  3. 启动 AgentCore-Light，打开控制台。
  4. 点击启动蓝牙模式。
  5. 等待软件搜索并连接设备；设备绿灯呼吸即表示成功。

Linux 蓝牙由 AgentCore-Light 自动搜索和连接。通常无需先在系统蓝牙设置中手动配对；如未找到设备，请确认设备处于红灯闪烁状态，并确认系统蓝牙服务已开启。

#6. 使用 USB 串口连接

  1. 确保设备已经开机。
  2. 短按一次按键，确认黄灯开始闪烁。
  3. 使用支持数据传输的 Type-C 数据线连接设备与 Linux 电脑。
  4. 在控制台点击启动 USB 串口模式。
  5. 等待软件连接成功；设备绿灯呼吸即表示可以使用。

如果看到“权限不足”或软件找不到 USB 设备，请先完成第 3 章的权限设置，然后重新插拔数据线并重新扫描。

#7. 控制台与 AI 工具

设备绿灯呼吸后，可在控制台中：

  • 测试红、黄、绿灯以及闪烁效果；
  • 调整整体灯光亮度（默认 30%）；
  • 调整蜂鸣器开关和音量；
  • 查看电量、电压、USB 接入状态；
  • 在连接 AI 工具中按提示安装所需 AI 工具连接。

AI 工具连接完成后，设备可自动提示工作中、完成、报错和等待确认等状态。

#设备状态灯效对照

AI 工具工作时，设备会自动按下面的方式显示当前状态：

状态灯效说明
空闲 IDLE绿灯呼吸没有任务在跑；连续空闲会自动熄灯休眠
工作 BUSY黄灯慢闪正在调用工具或执行任务，约 1 秒闪一次
等待确认 WAIT_CONFIRM黄灯常亮需要你授权或确认
报错 ERROR红灯快闪任务失败或出错
任务完成 SUCCESS绿灯呼吸任务成功时绿灯呼吸并响「上行提示」音，5 秒后回到空闲

灯光亮度可在控制台调整（默认 30%）；蜂鸣器可以整体关闭，也可以单独调整音量。连续空闲 10 分钟会自动熄灯休眠，蓝牙断连 5 分钟自动关机，详见第 9 章。

#8. 设置为登录后自动启动（可选）

如需每次登录 Linux 后自动运行 AgentCore-Light，在软件解压目录中执行一次：

bash
./AgentCore-Light install

之后软件会作为当前用户的后台服务运行。一般客户无需输入其他命令；如需关闭自启动，可在控制台中关闭对应选项。

#9. 待机、休眠与自动关机

#9.1 空闲时的呼吸灯

连接 AI 工具后，灯光会交给软件接管：没有任务在跑时，绿灯以低亮度呼吸显示，比正常工作亮度暗一些，也是省电设计。刚建立连接、软件还没接管灯光时，绿灯同样是呼吸显示——看到绿灯在缓慢地一亮一暗，就表示连接已经就绪。

#9.2 连续空闲自动熄灯（休眠）

连续空闲 10 分钟（默认）后，设备会熄灭全部状态灯、进入休眠，进一步省电。休眠期间连接保持不断；AI 工具有新任务时，灯会自动亮回来，不需要按任何按键。

#9.3 蓝牙断连自动关机

蓝牙模式下，如果连续 5 分钟没有连接（例如电脑关机、蓝牙关闭或软件退出），设备会自动关机；插着 USB 充电时同样会进入关机状态。需要使用时，长按按键约 3 秒重新开机。

上面两个时间都可以调整：空闲熄灯默认 10 分钟、断连关机默认 5 分钟，范围都是 0～3600 秒，设为 0 表示关闭对应的自动动作。开发者可通过 API 命令 IDLE_SLEEP_SEC:、BT_DISCONNECT_OFF_SEC: 修改（见 API 调用手册第 15 节）；普通用户如需修改，请联系售后。

#9.4 充电与续航

  • 使用常规 USB 电源为设备充电。
  • USB 接入且未充满时，充电指示灯亮；充满后完成指示灯亮。
  • 使用电池供电时，充电和完成指示灯均关闭，这是正常的节能设计。
  • 不使用时请长按按键关机。

#10. 常见问题

#软件无法启动

  • 确认已在软件目录执行过 chmod +x AgentCore-Light。
  • 请在终端中运行 ./AgentCore-Light，不要双击未知文件。

#USB 连接失败或提示权限不足

  • 确认已执行第 3 章的 dialout 权限命令，并已注销后重新登录。
  • 更换支持数据传输的 Type-C 数据线。
  • 确认设备处于黄灯闪烁的 USB 串口模式。

#蓝牙模式一直红灯闪烁

  • 确认 Linux 蓝牙已打开，且电脑具备蓝牙功能。
  • 在控制台点击“启动蓝牙模式”。
  • 关闭并重新开启蓝牙后，再启动一次蓝牙模式。

#灯光没有变化

  • 确认设备绿灯呼吸。
  • 在“灯光控制”中先测试任意颜色。
  • 确认亮度没有调到 0%。

#设备外壳上有灰尘或指纹，是别人用过的吗？

不是。每台设备出厂前都经过组装和完整功能测试（开机、灯效、蜂鸣器、按键），测试、装箱时会接触工作台，外壳上留下少量灰尘或指纹属于正常现象，不影响使用。用包装内附带的酒精棉片擦拭一遍即可擦净，功能没有问题。

#空闲一会儿，灯自己灭了

不是故障：连续空闲 10 分钟设备会自动熄灯休眠，连接并没有断开，AI 工具有新任务时会自动亮回来，不需要按任何按键。详见 9.2 连续空闲自动熄灯（休眠）。

#设备自己关机了

蓝牙模式下连续 5 分钟没有连接（电脑关机、蓝牙关闭或软件退出），设备会自动关机，插着 USB 充电时也一样。长按按键约 3 秒即可重新开机。详见 9.3 蓝牙断连自动关机。

#11. 使用注意事项

  • 请勿自行拆开设备、短接接口或使用不匹配的电源。
  • 请避免在潮湿、高温或易燃环境中使用和充电。
  • 固件升级、维修或异常排查请联系售后，不建议客户自行操作。
