四步完成设置

第 1、4 步所有系统都一样，第 2、3 步按你使用的系统显示。

  1. 1

    长按按键，开机 所有系统一样

    按住设备上的按键约 3 秒后松开。三色灯会短暂亮起，随后停在红灯闪烁——表示设备已开机，正在等待连接。

    插入 USB 线不会自动开机，仍需长按按键。关机同样长按 3 秒。

  2. 2

    装上客户端 按你的系统

    1. 在上方下载 AgentCore-Light.zip，解压得到 AgentCore-Light.exe。
    2. 双击 AgentCore-Light.exe 运行。客户端会打开一个浏览器页面，即控制台。

    Windows 弹「已保护你的电脑」怎么办？

    点「更多信息」→「仍要运行」。软件未购买付费的代码签名证书，新版本下载量较少，被 SmartScreen 拦截属于正常现象，并非病毒。若杀毒软件报警或隔离了文件，请将其加入信任区。

    1. 在上方下载 AgentCore-Light-mac.zip，解压得到 AgentCore-Light.app。
    2. 把 AgentCore-Light.app 拖进「应用程序」文件夹。请勿跳过此步——若直接在解压目录中运行，后续的开机自启、AI 工具连接和在线更新都会异常。
    3. 在「应用程序」中找到它，按住 Control 点按（或右键）图标，选「打开」，再确认一次。

    Mac 说「无法验证开发者」怎么办？

    打开「系统设置 → 隐私与安全性」，找到刚才被拦截的提示，点「仍要打开」。macOS 15 及之后 Control 点按不再有效，只能使用此方法。

    如果提示「已损坏，无法打开」，打开「终端」执行下面这行，再重新打开：

    xattr -dr com.apple.quarantine /Applications/AgentCore-Light.app

    如果是双击完全没反应，通常是未拖入「应用程序」文件夹，请回到上文第 2 步。

    1. 在上方下载 AgentCore-Light-linux.tar.gz，解压。
    2. 打开终端，进入解压后的目录。
    3. 首次运行需先赋予执行权限，然后启动：

    chmod +x AgentCore-Light ./AgentCore-Light

    不要用 sudo ./AgentCore-Light 启动。

    软件全程以普通用户身份运行，不需要也不应该提权。只有下面第 3 步给串口权限的那一条命令需要 sudo。

  3. 3

    连上电脑 按你的系统

    设备开机后会自动进入蓝牙模式，此时状态灯红灯闪烁，表示它正在等待电脑连接。连上之后红灯就会变成绿灯呼吸（灯光缓慢地一亮一暗）。

    下面两种连接方式任选一种：蓝牙无需插线，适合日常使用；USB 连接更稳定，蓝牙不便时可选用。

    蓝牙 推荐

    1. 打开「设置 → 蓝牙和设备 → 添加设备 → 蓝牙」，等列表中出现 AgentCore-Light，选中它。
    2. 点进它的设备详情页，再点一次「连接」。仅完成配对还不够，这一步必须操作。
    3. 回到客户端，点「启动蓝牙模式」。

    在 Windows 中它可能显示为音频设备，名称也不相同——这是为了让 Windows 稳定管理连接，不会播放电脑声音。

    1. 在客户端里点「启动蓝牙模式」，软件会自动搜索并连接。
    2. 无需在系统「蓝牙」设置中手动添加。
    1. 在客户端里点「启动蓝牙模式」，软件会自动搜索并连接。
    2. 无需在系统蓝牙设置中手动添加。若电脑没有蓝牙，请使用右侧的 USB 方式。

    USB 线 蓝牙不方便时

    1. 在设备上短按一次按键，切换到 USB 串口模式（黄灯闪烁）。
    2. 用可传输数据的 Type-C 线连接到电脑。部分线缆仅支持充电，无法识别设备，请更换一根。
    3. 在客户端里点「启动 USB 串口模式」。

    首次使用 USB 需先为当前账户授予串口权限，执行后请注销并重新登录（仅关闭终端窗口无效）：

    sudo usermod -aG dialout $USER

    连接成功的标志：设备绿灯呼吸（缓慢地一亮一暗），客户端显示设备已连接。两种连接不能同时开启；如需切换，短按按键即可。

  4. 4

    测试灯光与蜂鸣器 所有系统一样

    1. 客户端启动后会自动打开一个浏览器页面，即控制台。若未自动打开，请手动访问 http://127.0.0.1:18793/。
    2. 在「灯光控制」中分别点击红灯、黄灯、绿灯，确认设备同步亮起。
    3. 点击蜂鸣器，确认是否有提示音。

    灯光与蜂鸣器均正常，即表示设备工作正常，可以开始使用。

    三项都正常，现在可以贴磁铁片了。如果哪一项不正常，请先别贴，联系我们处理——磁铁片撕开背胶粘贴后不支持无理由退货。

两种摆放方式

四步都测过之后，再来决定设备放在哪里。可以挂在显示器侧面，也可以立在桌面上，包装内附有一片磁铁片。

侧面磁吸 · 挂在显示器侧面

把磁铁片贴在显示器侧面，设备吸附上去、挂在屏幕边缘。不占桌面空间，抬眼就能看到当前状态。

底面磁吸 · 立在桌面上

把磁铁片贴在桌面上，设备吸附固定、立在桌上，摆放位置更灵活，也不容易被碰倒。

  1. 确认设备正常：如果第 4 步的灯光和蜂鸣器测试还没做完，请先做完再贴。
  2. 擦净设备：外壳上有灰尘或指纹，用包装内附带的酒精棉片擦拭一遍。
  3. 贴上磁铁片：撕开磁铁片的背胶，贴紧在选好的位置——显示器侧面或桌面。
  4. 吸附设备：把设备贴到磁铁片上，轻推一下确认吸稳。

状态灯含义速查

日常使用中可随时查阅。红、黄、绿三颗状态灯的含义固定不变。

还没连 AI 工具时

三色灯短暂亮起

正在开机，请稍候。

红灯闪烁

蓝牙模式，等待电脑连接。

黄灯闪烁

USB 模式，等待客户端连接。

绿灯呼吸

已连接，空闲待命。看到绿灯缓慢地一亮一暗即表示连接正常。

所有状态灯熄灭

已关机。长按按键 3 秒重新开机。

AI 工具接管后

空闲 IDLE

没有任务执行，绿灯低亮度呼吸。连续空闲 10 分钟会自动熄灯休眠，有新任务时自动亮起。

工作 BUSY

正在执行任务，黄灯慢闪（约 1 秒一次）。

等待确认 WAIT_CONFIRM

需要你确认授权，黄灯常亮。

报错 ERROR

任务失败或出错，红灯快闪。

任务完成 SUCCESS

任务成功，绿灯呼吸并响一声「上行提示」音，5 秒后回到空闲。任务完成以这声提示音为准。

上行提示音

按键只有一个，三种按法

机身只有一个按键，短按和长按对应不同功能。

短按一下

在蓝牙模式（红灯闪）和 USB 模式（黄灯闪）之间切换。两种连接只能开启一种，切换时短按即可。

长按 3 秒

开机和关机都是长按 3 秒。关机后所有状态灯熄灭，最为省电；插入 USB 线也不会自动开机，仍需长按按键。

Type-C 充电

用 Type-C 线充电，可边充边用。电量、电压、是否正在充电，均可在控制台中查看。

卡住了？

下面这几条能解决绝大多数问题，点开即可查看。

红灯一直在闪，连不上

红灯闪烁表示设备工作正常，正在等待电脑连接。问题通常出在电脑一侧：

  1. Windows：仅在客户端点击「启动蓝牙模式」不够。需先在「设置 → 蓝牙和设备」中完成配对，再进入设备详情页点击一次「连接」，然后回到客户端启动蓝牙模式。
  2. 确认设备未被其他电脑或手机连接——蓝牙一次只能连接一台设备。
  3. 若始终无法连接，可改用 USB：短按一次按键切换至黄灯闪烁，插入数据线，并在客户端点击「启动 USB 串口模式」。
黄灯一直在闪，连不上

黄灯闪烁表示设备已切换到 USB 模式，正在等待客户端连接。请逐项确认：

  • 是否已在客户端点击「启动 USB 串口模式」？
  • 数据线是否仅支持充电？请更换一根可传输数据的 Type-C 线。
  • 设备是否确实处于 USB 模式？短按一次按键可在两种模式间切换。
  • Linux：是否已授予串口权限？授权后需注销并重新登录才生效，仅关闭终端窗口无效。
客户端说连上了，但灯不亮
  • 请先在控制台的「灯光控制」中手动点击红灯。若灯正常亮起，说明连接没有问题。
  • 检查亮度是否被调至 0%。
  • AI 工具接管灯光后，灯光会跟随 AI 的状态变化。空闲时为绿灯低亮度呼吸，亮度较低属于正常现象。
过一会儿灯自己灭了

属于正常现象，并非故障。AI 工具接管灯光后，连续空闲 10 分钟（默认）会自动熄灭全部状态灯并进入休眠以节省电量，连接不会中断——AI 有新任务时会自动亮起，无需按任何按键。

如需调整时长或关闭该功能，请查阅完整手册第 8 章。

设备自己关机了

同样属于正常现象。蓝牙模式下，连续 5 分钟无连接（电脑关机、蓝牙关闭或客户端退出）设备会自动关机以节省电量，即使正在通过 USB 充电也会关机。

长按按键 3 秒即可重新开机。该时长同样可以调整或关闭，详见完整手册。

系统或杀毒软件说这个软件是病毒

软件由独立开发者制作，未购买付费的代码签名证书，因此首次运行时可能被 Windows SmartScreen、macOS 的 Gatekeeper 或杀毒软件拦截——这是缺少签名导致的，并非软件包含病毒。

各系统的提示内容与处理方法，完整手册开头有专门章节说明，按步骤操作即可。
