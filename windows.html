第一次运行被系统拦住了？

软件没有购买付费的代码签名证书，Windows 或杀毒软件提示“不安全”属于正常现象，不是病毒。

  • “Windows 已保护你的电脑” → 点“更多信息”，再点“仍要运行”
  • 浏览器提示“不常下载，可能不安全” → 在下载列表里选“保留”
  • 杀毒软件报警、或文件被隔离 → 在杀毒软件里加入信任；已被隔离的到“Windows 安全中心 → 保护历史记录”恢复
看详细说明 → 2.2 系统提示“不安全”怎么办

适用产品：AgentCore-Light 桌面状态指示灯

适用软件：AgentCore-Light Windows 客户端

磁铁片粘贴与售后提醒

包装内附有磁铁片，方便将设备固定在合适的位置。请在收到商品后，先完成开机、连接、灯光、蜂鸣器等全部功能测试，再决定粘贴位置。磁铁片撕开背胶并粘贴后，不支持无理由退货。如发现商品异常，请勿粘贴，先联系售后处理。

包装内附有一片酒精棉片

设备在出厂组装和测试时会接触工作台，外壳上可能留下少量灰尘或指纹，属于正常现象——用包装内附带的酒精棉片擦拭一遍即可擦净。每台设备出厂前都做过完整功能测试，灯效、蜂鸣器、按键均确认正常，功能没有问题，请放心使用。

AgentCore-Light 是一台通过三色灯和提示音展示电脑工作状态的桌面设备。它可使用蓝牙无线连接，也可通过 USB 数据线连接电脑。电脑端软件可手动控制灯光和蜂鸣器，也可连接 AI 工具，让设备自动显示工作、完成、报错或等待确认等状态。

#1. 产品状态速查

指示状态含义您需要做什么
三色灯短暂亮起设备正在开机等待进入连接状态
红灯闪烁蓝牙模式，等待电脑连接在 Windows 和 AgentCore-Light 软件中连接蓝牙
黄灯闪烁USB 串口模式，等待电脑软件连接插入 USB 数据线，并在软件中启动 USB 串口模式
绿灯呼吸当前连接方式已建立，设备处于空闲待命状态可以开始使用软件、灯光控制或 AI 工具
所有状态灯熄灭设备已关机长按按键 3 秒开机

「绿灯呼吸」指绿灯缓慢地一亮一暗，表示设备已连接、正在待命，不是闪烁也不是故障。

红、黄、绿三色灯用于显示工作状态；充电/充满指示灯只会在 USB 已接入时亮起。使用电池供电时，充电指示灯与充满指示灯均会关闭，以节省电量。

#2. 首次使用

#2.1 准备工作

  1. 为设备充电，或确认设备电量充足。
  2. 解压下载到的 AgentCore-Light.zip，得到主程序 AgentCore-Light.exe。
  3. 如使用 USB 连接，请使用支持数据传输的 Type-C 数据线；
  4. 如使用蓝牙连接，请确认电脑具有蓝牙功能并已打开蓝牙。

第一次运行 AgentCore-Light.exe 时，Windows 可能弹出“已保护你的电脑”，或者杀毒软件报警。这是未签名软件的正常现象，不是软件有问题，处理方法见下一节 2.2。

#2.2 系统提示“不安全”怎么办

AgentCore-Light 由一个独立开发者制作，没有购买付费的代码签名证书，也没有做发布者认证。所以第一次运行时，Windows 或杀毒软件可能会拦一下——这是缺少签名导致的，不是软件里有病毒。

为什么会被拦？

  • Windows 的 SmartScreen 主要看“这个文件有多少人下载过”。刚发布的新版本下载量少，就会被标成“不常见的应用”，这跟文件本身是否安全没有关系。
  • 杀毒软件对“没有签名、又不是大众软件”的程序普遍采取保守策略，常见做法是直接拦下或隔离，宁可错杀。

这个软件实际上做什么：

  • 只在本机运行。控制台网页只监听 127.0.0.1，也就是只有这台电脑打得开，同一个局域网里的其它设备也访问不到。
  • 除了检查软件更新，不向外部发送任何数据。
  • 开机自启动写在当前用户的注册表项里，不需要管理员权限，也不会改动系统设置或其它软件。

按提示类型处理：

① 蓝色窗口“Windows 已保护你的电脑”

这是 Windows 自带的 SmartScreen 拦截。点击窗口里的 “更多信息”，下面会多出一个 “仍要运行” 按钮，点它就能启动。

② 浏览器提示“不常下载，可能不安全”

在浏览器的下载列表里找到刚下载的压缩包，选择 “保留”（Edge 里是“仍然保留”）。

③ 杀毒软件报毒，或文件已被隔离 / 删除

先把文件恢复出来：

  • 打开 Windows 安全中心 → 病毒和威胁防护 → 保护历史记录，找到被处理的 AgentCore-Light.exe，点 “操作”，选择“允许”或“还原”。

再把它加入信任列表，避免以后每次都被拦：

  • Windows 安全中心 → 病毒和威胁防护 → “病毒和威胁防护设置”下的“管理设置” → 拉到底部“排除项” → “添加或删除排除项” → “添加” → “文件”，选中 AgentCore-Light.exe。
  • 第三方杀毒软件（360 安全卫士、火绒、腾讯电脑管家等）：在“信任区 / 白名单 / 排除项”里添加这个文件，或对报警弹窗选择“恢复并信任”。

建议在下载完成后、第一次运行之前，就先把 AgentCore-Light.exe 加进杀毒软件的信任列表，可以省掉后面反复被拦的麻烦。

运行之后还是不放心？

  • 可以把 AgentCore-Light.exe 上传到 https://www.virustotal.com/，让七十多家杀毒引擎同时扫描。未签名的个人软件常有一两家误报，只要不是大面积报毒，就属于误报。
  • 想确认软件的联网行为，可以在控制台里看事件流：它只和你通过 USB 或蓝牙连接的设备通信。

#2.3 开机

  1. 长按设备按键约 3 秒。
  2. 到达开机时间后，设备会立即显示开机灯效；
  3. 开机后默认进入蓝牙模式，红灯闪烁表示正在等待电脑连接。

#2.4 关机

长按设备按键约 3 秒。达到时间后，设备会立即关闭状态灯并进入低功耗关机状态。

插入 USB 用于充电或 USB 通信，不会自动开机。需要使用设备时，仍需长按按键 3 秒开机。

#3. 使用蓝牙连接（推荐日常无线使用）

蓝牙模式适合设备放在桌面上、希望减少线缆的场景。

#3.1 在 Windows 中配对

  1. 开机后确认设备红灯正在闪烁。
  2. 打开 Windows：设置 → 蓝牙和设备 → 添加设备 → 蓝牙。
  3. 在列表中选择 AgentCore-Light。
  4. 按 Windows 提示完成配对。
  5. 在设备详情页点击连接，直到 Windows 显示已连接。
  6. 设备绿灯呼吸，表示蓝牙业务连接已准备就绪。

首次配对完成后，后续通常无需重复配对。

#3.2 在 AgentCore-Light 中连接

  1. 双击运行 AgentCore-Light.exe。
  2. 会自动跳转到浏览器配置页面，如果没有跳转，可自行进入配置网页http://127.0.0.1:18793/。
  3. 点击启动蓝牙模式。
  4. 等待软件显示设备已连接。

蓝牙模式下，Windows 可能把设备显示为音频设备。这是为了让 Windows 稳定管理经典蓝牙连接；实际的灯光和蜂鸣器控制由蓝牙数据通道完成，不会播放电脑声音。

#4. 使用 USB 串口连接

USB 串口模式适合希望使用有线连接、无需电脑蓝牙的场景。

#4.1 切换到 USB 模式

  1. 确保设备已经开机。
  2. 短按一次设备按键。
  3. 黄灯开始闪烁，表示设备已切换到 USB 串口模式，正在等待电脑软件连接。

#4.2 在电脑上连接

  1. 用支持数据传输的 Type-C 数据线连接设备和电脑。
  2. 打开 AgentCore-Light.exe。
  3. 会自动跳转到浏览器配置页面，如果没有跳转，可自行进入配置网页http://127.0.0.1:18793/。
  4. 点击启动 USB 串口模式。
  5. 等待软件连接成功；设备绿灯呼吸即表示可以使用。

如果软件停止 USB 串口服务，设备会自动回到黄灯闪烁状态，等待下一次连接。

#5. 在两种连接方式之间切换

设备开机后默认蓝牙模式。每次短按一次按键即可在两种模式之间切换：

text
蓝牙模式（红灯闪烁）
        ⇅ 短按按键
USB 串口模式（黄灯闪烁）

切换模式时，设备会关闭另一种通信方式，以减少功耗并避免电脑同时连接两种通道造成混乱。

软件中点击“启动蓝牙模式”或“启动 USB 串口模式”时，也会自动关闭另一种软件连接方式。

#6. 软件基础操作

设备连接成功后，可在 AgentCore-Light 控制台完成以下操作。

#6.1 手动测试灯光

在“灯光控制”区域可直接测试红灯、黄灯、绿灯的点亮或闪烁效果，也可执行全部熄灭、全部点亮等测试。

#6.2 调整亮度

设备默认灯光亮度为 30%，兼顾桌面观感和续航。

如需更亮：

  1. 在控制台找到“亮度”滑块。
  2. 向右拖动提高亮度，向左拖动降低亮度。
  3. 松开滑块后，设置会立即发送给设备并保存在本机；下次软件启动或设备重新连接时会自动恢复。

#6.3 蜂鸣器

可在控制台中开启或关闭蜂鸣器，并调节音量。建议在安静环境中先使用较低音量进行测试。

#6.4 电池电量

设备连接后，控制台会显示：

  • 当前电量百分比；
  • 电池电压；
  • 当前是否接入 USB；
  • 最近一次状态更新时间。

插入 USB 时：未充满会点亮充电指示灯；电量充满后点亮完成指示灯。拔掉 USB 后，两颗充电相关指示灯会自动熄灭。

#6.5 退出软件

想彻底关掉软件（比如要让这台电脑不再跟随 AI 工具点灯），有两种方式，任选一种：

  1. 在控制台里退出（推荐）：点右上角的「退出」按钮，确认一下就行。界面和后台服务都会停下来，浏览器里的控制台页面可以直接关掉。
  2. 双击退出脚本：在软件所在文件夹（或卖家给的软件包里）双击 退出AgentCore-Light.cmd。控制台打不开、或者找不到退出按钮时用这条。

两种方式都不会关掉开机自启：以后开机还是会自动启动。想连开机自启也关掉，请在控制台顶栏关闭「开机自启」。

想再用时，双击桌面上的 AgentCore-Light 图标即可。

#7. 连接 AI 工具

如需让 AI 工作状态自动显示在设备上：

  1. 先按照第 3 或第 4 章完成设备连接，确认设备绿灯呼吸。
  2. 在软件中打开连接 AI 工具。
  3. 按页面提示选择并安装需要使用的 AI 工具连接。
  4. 按提示重启对应 AI 工具或新建会话。
  5. AI 工具开始工作后，设备会自动显示对应灯效；例如工作中、完成、报错或等待确认。

#豆包（Doubao）的特别说明

豆包桌面版没有 Hook 可以接，所以用的是内置监听：在「连接 AI 工具」里把「豆包（Doubao）」装上就行，不用重启豆包，也不用额外装任何东西。

装好之后正常用豆包：

  1. 你把问题发出去 → 状态灯亮忙碌；
  2. 豆包答完 → 状态灯给一次完成提示，然后回到待机。

几点要知道：

  • 支持 Windows / macOS 桌面版豆包，Linux 上豆包的安装方式比较多（部分发行版有原生包，部分走 Wine），同样尝试支持；
  • 如果装了豆包但灯不亮，把软件的日志发给我们即可——软件每 5 秒会记一行"找没找到豆包日志"，一眼就能看出问题在哪；
  • 判定方式是读豆包自己写的运行日志里两条"请求记录"（发问题、答完各一条），不截屏、不读聊天内容、不监听键盘；判断全在本机完成；
  • 豆包最小化或者被别的窗口挡住都没关系，答案出来照样会亮；发完就把豆包最小化去做别的事也完全可以；
  • 目前只识别"发出问题"和"回答完成"两个节点，豆包要求你确认之类的中间状态不单独上报；
  • 如果豆包大版本更新后识别失效，联系我们更新软件即可（软件里也留了自检日志，能一眼看出是豆包改版了）。

#设备状态灯效对照

AI 工具工作时，设备会自动按下面的方式显示当前状态：

状态灯效说明
空闲 IDLE绿灯呼吸没有任务在跑；连续空闲会自动熄灯休眠
工作 BUSY黄灯慢闪正在调用工具或执行任务，约 1 秒闪一次
等待确认 WAIT_CONFIRM黄灯常亮需要你授权或确认
报错 ERROR红灯快闪任务失败或出错
任务完成 SUCCESS绿灯呼吸任务成功时绿灯呼吸并响「上行提示」音，5 秒后回到空闲

灯光亮度可在控制台调整（默认 30%）；蜂鸣器可以整体关闭，也可以单独调整音量。连续空闲 10 分钟会自动熄灯休眠，蓝牙断连 5 分钟自动关机，详见第 8 章。

如果暂时不需要 AI 自动联动，也可以只使用软件的手动灯光和蜂鸣器控制功能。

#8. 待机、休眠与自动关机

#8.1 空闲时的呼吸灯

连接 AI 工具后，灯光会交给软件接管：没有任务在跑时，绿灯以低亮度呼吸显示，比正常工作亮度暗一些，也是省电设计。刚建立连接、软件还没接管灯光时，绿灯同样是呼吸显示——看到绿灯在缓慢地一亮一暗，就表示连接已经就绪。

#8.2 连续空闲自动熄灯（休眠）

连续空闲 10 分钟（默认）后，设备会熄灭全部状态灯、进入休眠，进一步省电。休眠期间连接保持不断；AI 工具有新任务时，灯会自动亮回来，不需要按任何按键。

#8.3 蓝牙断连自动关机

蓝牙模式下，如果连续 5 分钟没有连接（例如电脑关机、蓝牙关闭或软件退出），设备会自动关机；插着 USB 充电时同样会进入关机状态。需要使用时，长按按键约 3 秒重新开机。

上面两个时间都可以调整：空闲熄灯默认 10 分钟、断连关机默认 5 分钟，范围都是 0～3600 秒，设为 0 表示关闭对应的自动动作。开发者可通过 API 命令 IDLE_SLEEP_SEC:、BT_DISCONNECT_OFF_SEC: 修改（见 API 调用手册第 15 节）；普通用户如需修改，请联系售后。

#8.4 充电与续航建议

  • 可使用常规 USB 电源为设备充电。
  • 不使用设备时，长按按键关机，以获得更低待机功耗。
  • 长时间不用时，建议每隔一段时间补充电量，避免电池长期过度放电。

#9. 常见问题

#杀毒软件说这个软件是病毒

几乎都是误报。AgentCore-Light 没有购买代码签名证书，新版本下载量又少，容易被“宁可错杀”的规则拦下。软件只在本机运行、不向外部发送数据，具体说明和处理步骤见 2.2 系统提示“不安全”怎么办。

#按住按键后设备没有开机

  • 请确认按键持续按住约 3 秒。
  • 请先为设备充电后再试。
  • USB 接入不会自动开机，仍需长按按键。

#蓝牙模式一直红灯闪烁

  • 确认 Windows 蓝牙已打开。
  • 首次使用请先在 Windows 设置中配对 AgentCore-Light。
  • 配对后请在 Windows 设备详情页点击“连接”。
  • 再回到 AgentCore-Light 的蓝牙页面启动蓝牙模式。

#USB 模式一直黄灯闪烁

  • 确认已短按按键切换到 USB 模式。
  • 更换为支持数据传输的 Type-C 数据线。
  • 确认 AgentCore-Light 的 USB 串口页面已点击“启动 USB 串口模式”。

#软件显示连接成功，但灯光没有变化

  • 确认设备绿灯呼吸。
  • 在“灯光控制”中先测试红、黄、绿灯。
  • 确认亮度滑块未设置为 0%。
  • 尝试关闭并重新启动对应的蓝牙或 USB 串口模式。

#蓝牙和 USB 能否同时使用？

不能。设备一次只启用一种通信模式；这是为了降低功耗并保持连接稳定。短按设备按键即可切换。

#设备外壳上有灰尘或指纹，是别人用过的吗？

不是。每台设备出厂前都经过组装和完整功能测试（开机、灯效、蜂鸣器、按键），测试、装箱时会接触工作台，外壳上留下少量灰尘或指纹属于正常现象，不影响使用。用包装内附带的酒精棉片擦拭一遍即可擦净，功能没有问题。

#空闲一会儿，灯自己灭了

不是故障：连续空闲 10 分钟设备会自动熄灯休眠，连接并没有断开，AI 工具有新任务时会自动亮回来，不需要按任何按键。详见 8.2 连续空闲自动熄灯（休眠）。

#设备自己关机了

蓝牙模式下连续 5 分钟没有连接（电脑关机、蓝牙关闭或软件退出），设备会自动关机，插着 USB 充电时也一样。长按按键约 3 秒即可重新开机。详见 8.3 蓝牙断连自动关机。

#10. 使用注意事项

  • 请勿自行拆开设备、短接接口或使用不匹配的电源。
  • 请避免在潮湿、高温或易燃环境中使用和充电。
  • 仅使用正常的 USB 供电设备和合格数据线。
  • 固件升级、维修或异常排查请联系售后，不建议客户自行操作。
